# Telekom Churn Paneli
React + TypeScript + Vite + Tailwind CSS ile müşteri yönetim paneli. Veri: Telco Customer Churn (150 kayıtlık örnek), LocalStorage'da saklanır.

CRUD: Ekle · Listele (arama + filtre) · Güncelle · Sil

## Çalıştırma
npm install && npm run dev

## Yayın (Netlify)
Build: `npm run build` · Publish dir: `dist`
